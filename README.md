# Telegram-бот для трекинга медицинских анализов пользователя по фотографии/файлу

**Тема проекта**

Разработка Telegram-бота для автоматического распознавания, структурирования и трекинга результатов медицинских анализов пользователя по фотографии или файлу.

**Команда**

* Участник: Рябинина Мария Викторовна (@Marusay_5)
* Куратор: Белый Роман (@rbyelyy)

Цель проекта

Разработать сервис, который позволяет пользователю загрузить фотографию или файл с результатами медицинских анализов, автоматически извлечь из документа показатели и их значения, привести их к структурированному виду и сохранять результаты для последующего отслеживания изменений показателей во времени.

Итоговым интерфейсом сервиса будет Telegram-бот.

**План работы**

Чекпойнт 1 — данные и постановка задачи

* Поиск и анализ открытых датасетов медицинских документов.
* Изучение существующих решений и подходов в области MedTech.
* Выбор датасета или нескольких источников данных.
* Разведочный анализ данных (EDA).
* Формализация ML-задачи.
* Определение метрик качества.
* Формирование протокола оценки моделей.

Результат: выбран набор данных, определена постановка задачи и метрики качества.

Чекпойнт 2 — модели и эксперименты

* Реализация baseline-решения.
* Эксперименты с существующими архитектурами распознавания документов.
* Исследование подходов на основе OCR и vision-language models.
* Сравнение моделей по выбранным метрикам.
* Анализ ошибок.

Результат: рабочая модель и результаты сравнения нескольких подходов.

Чекпойнт 3 — сервис

* Разработка Telegram-бота.
* Интеграция ML-модели.
* Реализация загрузки фотографий и файлов с медицинскими анализами.
* Структурирование распознанных показателей.
* Реализация хранения и отображения истории результатов пользователя.
* Развертывание сервиса.

Результат: работающий end-to-end прототип сервиса.

Чекпойнт 4 — предзащита

* Финальное сравнение моделей.
* Анализ полученных метрик.
* Сравнение итогового решения с baseline.
* Анализ типичных ошибок и ограничений системы.
* Подготовка демонстрации сервиса.
* Подготовка презентации проекта.

Результат: готовый сервис, экспериментальные результаты и презентация для предзащиты.

Итог проекта

Работающий Telegram-бот, позволяющий загрузить медицинский анализ в виде фотографии или файла, автоматически извлечь показатели и отслеживать их изменения во времени.
